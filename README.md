# Data Structures and Algorithms (DSA) Practicals

This repository contains C implementations for 9 Data Structures and Algorithms (DSA) practical assignments.

## Practicals Overview

| Practical | File | Description |
| :--- | :--- | :--- |
| **Practical 1** | [`DSA/practical1.c`](DSA/practical1.c) | Menu-Driven Program to Search Roll Numbers Using Linear Search and Binary Search |
| **Practical 2** | [`DSA/practical2.c`](DSA/practical2.c) | Sorting First-Year Student Percentages Using Selection Sort and Bubble Sort |
| **Practical 3** | [`DSA/practical3.c`](DSA/practical3.c) | Hash Table-Based Telephone Directory using linear probing, quadratic probing, and double hashing |
| **Practical 4** | [`DSA/practical4.c`](DSA/practical4.c) | Club Member Management Using a Singly Linked List (Pinnacle Club membership) |
| **Practical 5** | [`DSA/practical5.c`](DSA/practical5.c) | Ticket Booking System of Cinemax Theatre Using a Doubly Linked List |
| **Practical 6** | [`DSA/practical6.c`](DSA/practical6.c) | Expression Conversion (Infix to Postfix) and Evaluation Using a Stack |
| **Practical 7** | [`DSA/practical7.c`](DSA/practical7.c) | Simulation of a Job Queue in a Pizza Parlour Using a Queue (FCFS) |
| **Practical 8** | [`DSA/practical8.c`](DSA/practical8.c) | Implementation and Operations on a Binary Search Tree (BST) |
| **Practical 9** | [`DSA/practical9.c`](DSA/practical9.c) | Graph Representation of Flight Paths and Connectivity Check |

## Compilation & Execution

To compile and run any practical using `gcc`:

```bash
# Example for Practical 1
gcc DSA/practical1.c -o practical1
./practical1
```
